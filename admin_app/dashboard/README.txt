Dashboard

Run from the project root:

    streamlit run dashboard/dashboard.py

Required project folders:
    data/
    models/
    modules/
    utils/
    reports/

The dashboard expects:
    data/patients.csv
    data/medications.csv
    data/adherence.csv
    models/adherence_model.pkl
    models/scaler.pkl
    modules/*.py
    utils/preprocessing.py
